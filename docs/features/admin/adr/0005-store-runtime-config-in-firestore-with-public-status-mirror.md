# 0005 — Store runtime config in Firestore with a public status mirror read directly by the site

- **Status:** Accepted
- **Date:** 2026-10-07
- **Deciders:** Тарас Щадило (Tech Lead) + Claude під час Socratic-проходу `design`

## Context

Типові ліміти й перемикачі сервісу сьогодні — env-змінні, тож зміна = повторне розгортання. Сервер має бачити зміну ≤ 60 с; сайт (зокрема Гість) має бачити банер обслуговування й стан перемикачів ≤ 5 хв і не будити сервер.

## Decision drivers

- NFR «Набуття чинності змінами, які застосовує сервер» ≤ 60 с.
- NFR «Поява чи зникнення банера … і нового стану перемикачів … для нових відвідувань» ≤ 5 хв.
- NFR «Банер і стан перемикачів на сайті» — 0 запитів до хмарного сервера; NFR «Сон сервера при відкритій адмінці».
- AC-33 — зміна налаштування й запис журналу разом (ADR-0007).

## Considered options

1. **Firestore + публічне дзеркало** — закритий документ налаштувань (сервер кешує в пам'яті, лінивий TTL 30 с) + публічний документ стану (банер і перемикачі), який правила дозволяють читати всім; обидва й журнал — одним атомарним записом.
2. **Публічний JSON у GCS** — `status.json` у новому публічному бакеті з кешем 5 хв; запис не атомарний із журналом.
3. **Firebase Remote Config** — готовий сервіс віддалених налаштувань; не атомарний із журналом у Firestore, клієнтський кеш за замовчуванням 12 год, новий SDK.

## Decision outcome

**Chosen:** Option 1. Один атомарний batched write оновлює налаштування, публічне дзеркало й журнал; сайт читає дзеркало напряму з Firestore (1 читання на візит), сервер — лінивий кеш без фонового опитування.

## Consequences

**Positive**
- 0 запитів до сервера для банера й перемикачів; Firebase SDK уже в бандлі.
- Атомарність з журналом без додаткових механізмів.
- Env-значення лишаються лише початковими (seed), якщо документа ще немає.

**Negative**
- Публічно читаний документ: суворо лише банер і стан перемикачів — жодних лімітів чи особистих даних (правило в `firestore.rules` + тест).
- 1 читання Firestore на кожен візит сайту (зокрема гостей).

**Neutral**
- Лінивий TTL 30 с означає, що перша дія після зміни може бачити старе значення до 30 с — у межах 60 с.
