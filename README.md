# Chords Listener

Локальна програма, яка визначає акорди пісні з посилання на YouTube (або будь-який сайт, який підтримує yt-dlp), з аудіо/відеофайлу чи із запису з мікрофона. Акорди підсвічуються в такт музиці, їх легко транспонувати, спрощувати й копіювати. Аплікатури є для гітари, укулеле, піаніно й хендпана, а темп (BPM), удари такту й метроном допомагають грати разом із піснею.

Усе працює на твоєму компʼютері: сервер слухає лише `localhost`, пісні зберігаються в папці `data/`. Є й веб-версія без встановлення: **https://shchadylotaras.github.io/chords-listener/** (див. «Веб-версія»).

---

## Вимоги

| Що | Навіщо | Як встановити (macOS) |
|---|---|---|
| **ffmpeg** | декодування аудіо й відео | `brew install ffmpeg` |
| **uv** | Python 3.11 і залежності бекенду | `brew install uv` |
| **Node.js 20.19+ / 22+** | збірка веб-інтерфейсу | `brew install node@22` |
| **git + Xcode Command Line Tools** | лише для першого встановлення (бібліотеку madmom зібрано з GitHub) | `xcode-select --install` |
| Інтернет | завантаження з YouTube і перше встановлення | |

Перевірено на macOS (Apple Silicon, M4 Pro). Браузер: Chrome, Safari, Firefox.

## Запуск

```bash
./start.sh
```

Скрипт перевірить інструменти й підкаже, чого бракує. Далі він сам:

1. робить `uv sync` у `backend/`;
2. запускає `npm install`, якщо його ще не було;
3. збирає інтерфейс, якщо `frontend/dist` відсутній або старіший за код;
4. запускає сервер на `127.0.0.1:8765` і відкриває **http://localhost:8765**.

**Ctrl+C** зупиняє сервер.

Перший запуск триває кілька хвилин, бо треба встановити залежності. Далі програма стартує за пару секунд.

Змінні середовища (необовʼязково):

```bash
CHORDS_PORT=8766 ./start.sh        # інший порт
CHORDS_NO_OPEN=1 ./start.sh        # не відкривати браузер
CHORDS_DATA_DIR=~/Music/chords ./start.sh   # де зберігати пісні
CHORDS_MAX_DURATION_MIN=60 CHORDS_MAX_UPLOAD_MB=1000 ./start.sh   # ліміти (типово 30 хв і 500 МБ)
```

> Відкривай саме **localhost**, а не 127.0.0.1: YouTube не показує відео на сторінках з IP-адресою. Якщо ввести 127.0.0.1, програма сама перейде на localhost.

## Веб-версія (GitHub Pages)

Інтерфейс опубліковано і як звичайний сайт: **https://shchadylotaras.github.io/chords-listener/**. Встановлювати нічого не треба. Що саме працює, залежить від того, чи запущено сервер на твоєму компʼютері. Поточний режим показано в шапці сайту, клік по ньому відкриває налаштування зʼєднання.

| Режим | Коли | Що працює |
|---|---|---|
| **Програма на localhost** | відкрито http://localhost:8765 після `./start.sh` | усе: YouTube, файли, мікрофон; пісні в `data/` |
| **Локальний сервер ✓** (на сайті) | сайт знайшов `./start.sh`, запущений на твоєму компʼютері | те саме: розпізнає сервер (рушій madmom), бібліотека спільна з http://localhost:8765 |
| **Браузерний режим** (на сайті) | сервер не запущено | файли й записи з мікрофона розпізнаються прямо в браузері, пісні зберігаються в браузері лише на цьому пристрої (працюють історія, правки, перезавантаження сторінки); посилання на YouTube не працюють |

### Як підключити сайт до свого сервера

1. Один раз завантаж програму і встанови інструменти з розділу «Вимоги»:
   ```bash
   git clone https://github.com/shchadyloTaras/chords-listener.git
   ```
2. Запусти сервер і не закривай термінал:
   ```bash
   cd chords-listener && ./start.sh        # CHORDS_NO_OPEN=1 ./start.sh — не відкривати вкладку localhost
   ```
3. На сайті натисни «Браузерний режим» у шапці → «Перевірити зʼєднання». Chrome (версія 142+) спитає, чи дозволити сайту доступ до пристроїв у локальній мережі. Дозволь: так браузер захищає localhost від сторонніх сайтів. Після цього сайт підключається сам і, поки сервер не відповідає, перевіряє його кожні 10 секунд.
4. Якщо сервер працює на іншому порту, зміни «Адресу сервера» в тому ж вікні (наприклад, `http://localhost:8766`).

Якщо вставити посилання на YouTube у браузерному режимі, під полем зʼявиться ця сама інструкція. Щойно сервер підключиться, посилання можна розпізнати.

**Безпека.** Сервер приймає запити лише від `https://shchadylotaras.github.io` і від сторінок на localhost: CORS, відповідь на Private Network Access-запит Chrome (`Access-Control-Allow-Private-Network: true`). Зміни з будь-яких інших сайтів, як і раніше, відхиляються. Список сайтів можна задати так: `CHORDS_ALLOWED_ORIGINS=https://один.example,https://другий.example ./start.sh`. Він замінює типовий, а сторінки з localhost дозволені завжди.

**Якщо сайт не підключається:**

- Перевір, що сервер відповідає: http://localhost:8765/api/health.
- Якщо в Chrome доступ до локальної мережі відхилено, дозволь його в налаштуваннях сайту (значок ліворуч від адреси) і натисни «Перевірити зʼєднання».
- Safari може не пускати сторінку https до http://localhost. Тоді відкрий програму напряму, http://localhost:8765, там обмежень немає.
- Пісні з браузерного режиму й пісні сервера зберігаються окремо. На сайті видно обидва списки (браузерні позначені «На цьому пристрої»), а на http://localhost:8765 лише серверні.

**Публікація.** `.github/workflows/pages.yml` на кожен push у `main` запускає тести, збирає інтерфейс з базовим шляхом `/chords-listener/` і публікує його на GitHub Pages (Settings → Pages → Source: GitHub Actions). Зібрати й переглянути так само локально (результат іде в `frontend/dist-pages`, а `frontend/dist` лишається для `./start.sh`):

```bash
cd frontend && VITE_BASE=/chords-listener/ npm run build
VITE_BASE=/chords-listener/ npx vite preview --port 5184   # http://localhost:5184/chords-listener/
```

## Як користуватись

### 1. Додати пісню

- **Посилання.** Встав посилання на YouTube у велике поле: розпізнавання почнеться одразу. Підходять звичайні, `youtu.be`, `shorts` і `music.youtube.com` посилання; мітки часу й плейлисти в адресі ігноруються. Інші сайти теж працюють, якщо їх підтримує yt-dlp.
- **Файл.** Натисни «Вибрати файл» або перетягни файл будь-куди у вікно. Підходять mp3, m4a, wav, flac, ogg, opus, webm, mp4, mov і все, що відкриває ffmpeg.
- **Мікрофон.** «Записати з мікрофона» → «Зупинити й розпізнати». Постав мікрофон ближче до джерела звуку.

Пісня тривалістю 3–4 хвилини обробляється приблизно за 3–6 секунд. Повторне посилання на вже розпізнану пісню, навіть в іншій формі, відкривається миттєво. Усі розпізнані пісні є в списку «Нещодавні» на головній сторінці.

### 2. Грати разом із піснею

- Вгорі сторінки великий **поточний акорд** (видно навіть з 2 метрів), **наступний** акорд, удари такту й аплікатура для гітари, укулеле, піаніно чи хендпана (кнопки «<» «>» перемикають варіанти аплікатури).
- Поруч **темп**, наприклад «113 BPM», і точки ударів такту, які блимають у ритм. Клік по темпу відкриває панель темпу:
  - графік темпу протягом пісні;
  - **«Половина ×½ / Подвоїти ×2»**, якщо програма сплутала темп удвічі (такти, лічильник, метроном і копіювання підлаштуються);
  - **«Тап»** (клавіша T): настукай темп сам і порівняй з розпізнаним;
  - **метроном** (клавіша K) з гучністю: клацає на кожну долю, сильна доля звучить вище. Кнопка метронома є й у плеєрі.
- **Хендпан.** Діаграма показує інструмент згори: які поля грати для акорду, і чого бракує («бракує: B · грай як G5»). Над акордом видно, скільки акордів пісні грається на твоєму хендпані, і кнопку, яка транспонує пісню в найзручнішу тональність («Транспонувати +5 → 92 %»). Стрій вибирається там же або в налаштуваннях панелі (⚙): «Мій хендпан» (типово A | D F A C G E C A) чи готові строї (D Kurd, D Celtic Minor, C# Amara та інші). Олівець відкриває редактор власного хендпана: дінг і 7–14 полів, порядок, октави, вставка списком нот.
- Під ним **аркуш акордів** розбитий на такти. Поточний такт і акорд підсвічені, сторінка прокручується за музикою. Якщо прокрутиш сам, зʼявиться кнопка «Повернутись до відтворення».
- **Клік по акорду** перемотує пісню на нього, а на паузі ще й програє його звук. Наведення курсора (або довге натискання на телефоні) відкриває картку акорду з аплікатурою та кнопками «Прослухати», «Копіювати», «Редагувати» і «Грати звідси».
- **Звук акорду.** Акорд звучить на обраному інструменті й саме так, як показує аплікатура (з транспонуванням, спрощенням і знаками):
  - гітара й укулеле: показаний варіант аплікатури, перебором від верхньої струни; піаніно: ноти з нотного стану, бас лівою рукою трохи раніше; хендпан: лише ті ноти акорду, що є на твоєму хендпані, арпеджіо знизу вгору (якщо жодної немає, зʼявиться підказка);
  - звучить клік по акорду на аркуші й таймлайні (коли пісня на паузі; під час відтворення клік лише перемотує, і чути сам запис), по плитці в «Акорди в пісні», по великому поточному чи наступному акорду вгорі;
  - аплікатура звучить завжди: клік по гітарній чи укулельній діаграмі грає акорд, по клавіші піаніно чи полю хендпана — одну ноту, деінде на діаграмі — увесь акорд; ноти, що звучать, підсвічуються;
  - кнопка «Прослухати» в картці акорду й клавіша **P** (поточний акорд, а якщо його немає — виділений чи наступний) теж звучать завжди;
  - у налаштуваннях панелі (⚙) можна вимкнути «Звук акорду при натисканні» (тоді клік по плитці в легенді знову копіює назву) і змінити гучність, кнопка поруч із повзунком програє акорд для перевірки;
  - звук синтезується прямо в браузері (Web Audio), нічого не завантажується. На iPhone та iPad Web Audio слухається перемикача беззвучного режиму: якщо акорд не чути, а пісню чути, вимкни беззвучний режим.
- **Таймлайн** (перемикач у панелі або клавіша V) показує акорди як блоки на хвилі звуку, з масштабом (Ctrl/⌘ + колесо).
- Кольори акордів ідуть за квінтовим колом, тож споріднені акорди мають схожі кольори.
- Внизу плеєр: хвиля для перемотування, швидкість 0.5–1.5× без зміни висоти тону, гучність. Для пісень з YouTube є кнопка «Відео».

#### Живе піаніно

Коли обрано піаніно, під великим акордом зʼявляється **«Живе піаніно»**: ноти пісні падають на клавіатуру, а клавіші натискаються й світяться саме тоді, коли нота звучить. Колір клавіші збігається з кольором акордів з такою ж основою, яскравість залежить від сили звуку, а на кожному натисканні клавіша коротко спалахує. Лінії з назвами акордів у стрічці показують, коли зміниться акорд.

- **Перше розпізнавання займає трохи часу.** Ноти знаходить нейромережа Basic Pitch (Spotify) прямо в браузері, на відеокарті: на Mac з M4 Pro це приблизно 0,7 с на хвилину звуку, тобто пісня на 15 хвилин готова за ~11 с. Без відеоприскорення розпізнавання значно довше (~30 с на хвилину). Поки воно триває, видно відсоток і кількість уже знайдених нот. Результат зберігається: на сервері в `data/tracks/<id>/notes.json`, у браузерному режимі в IndexedDB. Наступного разу ноти відкриваються миттєво, а після «Розпізнати заново» для акордів вони не зникають, бо звук той самий. Кнопка ↻ на панелі розпізнає ноти ще раз.
- **Синхронізація.** Якщо клавіші світяться раніше, ніж ти чуєш ноту (так буває з Bluetooth-навушниками, вони затримують звук на 100–300 мс), натисни «Синхронізація» й посунь повзунок праворуч. Якщо світяться пізніше, посунь ліворуч. Зсув запамʼятовується на цьому пристрої.
- Клавіатура підлаштовується під діапазон пісні (від 4 октав до всіх 88 клавіш). На телефоні видно ~3 октави, де звучить найбільше нот, а ноти поза ними переносяться на крайню октаву з позначкою ▲ / ▼.
- Звук акорду, який ти вмикаєш кліком, теж підсвічує клавіші, навіть на паузі. Якщо пісню транспоновано, клавіші показують ноти в новій тональності.
- Сховати панель можна кнопкою ✕, повернути вимикачем «Живе піаніно» в налаштуваннях панелі (⚙). У демо-пісні звуку немає, тому немає й нот.
- **Точність.** На синтетичних записах з відомими нотами панель знаходить 98 % нот, 88 % знайденого правильні; початок ноти визначається з похибкою ~2 мс (у 90 % випадків до 8 мс). У щільних міксах з вокалом зайвих нот більше: модель чує й голос, і гармоніки інструментів.

### 3. Транспонування й спрощення

- **− / +** у панелі (або `-` / `=`) транспонує на півтону, `0` повертає оригінал. Тональність показано як «Am → Cm».
- **«Спростити»** (S) показує прості акорди замість складних: Am7 → Am, G/B → G.
- **«Знаки»** перемикають написання: «Авто» (дієзи чи бемолі за тональністю), завжди `C#` або завжди `Db`.
- Якщо акорди легше грати з каподастром, зʼявиться підказка, наприклад «Капо 3: грай як Em C G D».

### 4. Копіювання

- **«Копіювати»** (або клавіша **C**) копіює всі акорди. Стрілка біля кнопки відкриває вибір формату:
  - **Такти:** `| Am | F | C | G |`
  - **З часом:** `0:12  Am`
  - **ChordPro:** `[Am]` для застосунків-пісенників
  - **Лише акорди:** `Am F C G`
- Там же можна завантажити `.txt` або `.cho`.
- Кожен рядок тактів має свою кнопку копіювання (зʼявляється при наведенні).
- Клік по номеру такту виділяє його, а Shift+клік виділяє діапазон. Потім можна «Копіювати» або «Зациклити» виділене.
- Кнопка копіювання на плитці в легенді «Акорди в пісні» копіює назву акорду (клік по самій плитці програє його звук).
- Скопійоване враховує транспонування, спрощення й обране написання знаків. Після кожного копіювання показується повідомлення й галочка.

### 5. Виправлення акордів

Подвійний клік по акорду (або F2 / E, коли акорд у фокусі) відкриває редактор з підказками. Зміни зберігаються одразу, і їх можна скасувати кнопкою «Відмінити» в повідомленні. Пункт «Скинути до розпізнаних» повертає оригінал. Пункт меню «Розпізнати заново» запускає аналіз ще раз; попередні правки при цьому зберігаються в резервній копії на диску.

### 6. Акаунт (необовʼязково)

Кнопка «Увійти» в шапці створює акаунт за поштою й паролем. Він потрібен лише для одного: щоб тема, мова, інструмент і вигляд акордів (спрощення, знаки, кількість тактів у рядку тощо) були однакові на всіх твоїх пристроях. Пісні, акорди й правки нікуди не надсилаються і лишаються на компʼютері чи в браузері. Без акаунта програма працює повністю.

### Гарячі клавіші

Клавіші не спрацьовують, поки курсор у текстовому полі. Вони працюють і з українською розкладкою. Повний список є у вікні `?`.

| Клавіша | Дія |
|---|---|
| Пробіл | відтворити / пауза |
| ← / → | назад / вперед на 5 с |
| Shift + ← / → | попередній / наступний акорд |
| `,` / `.` | повільніше / швидше |
| M | вимкнути / увімкнути звук |
| `-` `=` (або `[` `]`) | транспонувати вниз / вгору |
| 0 | оригінальна тональність |
| S | спрощені акорди |
| V | аркуш ↔ таймлайн |
| C | скопіювати всі акорди |
| F | стежити за відтворенням |
| L | зациклити поточний такт або виділення (ще раз — вимкнути) |
| I | гітара → укулеле → піаніно → хендпан |
| P | прослухати поточний акорд (або виділений / наступний) |
| T | відбити темп (тап) |
| K | метроном |
| ? | довідка з клавішами |
| Esc | закрити вікно / прибрати цикл / зняти виділення |

## Точність і поради

Розпізнавання працює на нейромережах [madmom](https://github.com/CPJKU/madmom), які переписано для швидкодії: пісня обробляється приблизно в 70–80 разів швидше, ніж звучить. Крім акордів, програма визначає ритм (долі й сильні долі), розмір 3/4 чи 4/4, темп і тональність. Якщо madmom недоступний, використовується запасний алгоритм на librosa.

**Результати тестів:**

| Набір | Збіг основи акорду | Збіг мажор/мінор | Тональність | Розмір |
|---|---|---|---|---|
| 8 синтетичних пісень | ~97 % | ~97 % | 8/8 | 8/8 |
| 14 випадкових синтетичних пісень | ~95 % | ~95 % | 14/14 | 14/14 |

На реальних записах відомі прогресії знаходяться правильно (наприклад, Em–C–G–D, G–D–Am–C).

**Що варто знати:**

- **Мажор і мінор іноді плутаються**, коли в аранжуванні звучить «чужа» терція або мінорний акорд зіграно арпеджіо.
- **Складні акорди показуються обережно.** Програма радше напише простий акорд, ніж вигадає зайвий: справжні 7, maj7 чи слеш-акорди іноді виходять звичайними тризвуками. Кнопка «Спростити» робить усе ще простішим.
- **Темп іноді визначається вдвічі повільнішим (або швидшим).** Буває в піснях без ударних. Акорди все одно на своїх місцях, але такти будуть удвічі довші. Виправ це одним кліком: клік по темпу → «Подвоїти ×2» чи «Половина ×½» (запамʼятовується для кожної пісні).
- **Акорди з низькою впевненістю** підкреслені пунктиром («Можлива неточність»).
- Розділення інструментів (Demucs) не встановлено, тому на дуже щільних міксах точність нижча.
- **Браузерний режим сайту** використовує легший алгоритм без нейромереж: на синтетичних піснях мажор/мінор збігається в ~91 % випадків (сервер ~95–97 %), а 7, maj7 і sus визначаються рідше. Для найкращого результату запусти `./start.sh`.

**Поради:**

- Оригінальний студійний запис дає кращий результат, ніж концертне відео чи кліп із вставками.
- Для запису з мікрофона потрібна тиша, мікрофон ближче до інструмента і хоча б кілька тактів гри.
- Якщо такти поставлені невдало, сітку ставить сама програма, а клік по акорду все одно перемотує точно на нього.
- Помилки легко виправити вручну (подвійний клік), а оригінал завжди можна повернути.

## Якщо щось не працює

**YouTube не завантажується** («Не вдалося завантажити», помилка 403). YouTube часто змінює сайт, тож онови yt-dlp:

```bash
cd backend && uv lock --upgrade-package yt-dlp && uv sync
```

Потім перезапусти `./start.sh`.

**«Відео недоступне для вбудовування».** Деякі власники забороняють показ свого відео на інших сайтах. Акорди й звук працюють як звичайно. Переконайся також, що відкрито `http://localhost:8765`, а не IP-адресу.

**Порт зайнятий.** `./start.sh` повідомить, якщо порт 8765 тримає інша програма. Подивитись, хто саме:

```bash
lsof -nP -iTCP:8765 -sTCP:LISTEN
```

Або запусти на іншому порту: `CHORDS_PORT=8766 ./start.sh`. Якщо програма вже запущена, скрипт просто відкриє її в браузері.

**Мікрофон не працює.** Запис можливий лише на `localhost` або через HTTPS. Дозволь доступ до мікрофона в налаштуваннях сайту в браузері.

**Перше встановлення падає на madmom.** Встанови інструменти розробника (`xcode-select --install`) і git, потім виконай `cd backend && uv sync`, щоб побачити подробиці.

**«Файл задовгий / завеликий».** Типові ліміти: 30 хвилин і 500 МБ. Змінити їх можна так: `CHORDS_MAX_DURATION_MIN=60 CHORDS_MAX_UPLOAD_MB=1000 ./start.sh`.

**Відкрити з телефону в тій самій мережі.** Сервер навмисно приймає лише localhost. Для доступу з мережі запусти бекенд з `--host 0.0.0.0` і `CHORDS_ALLOWED_HOSTS=<ip-компʼютера>`. Запис з мікрофона на телефоні без HTTPS не працюватиме.

**Почати з чистого аркуша.** Зупини сервер і видали папку `data/`. Окрему пісню можна видалити в меню сторінки пісні («Видалити пісню») або в списку «Нещодавні».

## Розробка

```bash
./dev.sh    # бекенд з автоперезапуском (127.0.0.1:8765) + Vite з HMR (http://localhost:5173)
            # інші порти: CHORDS_PORT=8766 CHORDS_DEV_PORT=5174 ./dev.sh
```

Перевірки:

```bash
cd backend && uv run pytest -q                       # API + рушій
cd backend && uv run python scripts/eval_engine.py   # точність рушія на синтетичних піснях
cd backend && uv run python scripts/analyze_file.py пісня.mp3   # акорди будь-якого файлу в терміналі
cd frontend && npx tsc -b && npx vitest run && npx oxlint && npx vite build
cd frontend && node scripts/eval-web-engine.ts --dir <папка з синтетичними піснями>   # точність браузерного рушія
cd frontend && node scripts/eval-transcription.ts   # точність і швидкість розпізнавання нот (живе піаніно)
```

Синтетичні пісні для оцінки: `cd backend && uv run python scripts/make_synthetic.py --out <папка>` (додай `--random 14` для випадкового набору).

Документація API доступна на http://localhost:8765/api/docs. Контракти (формати JSON, позначення акордів, API, клавіші, темп, режими сайту, Firebase і його емулятори) описано в `docs/SPEC.md`.
